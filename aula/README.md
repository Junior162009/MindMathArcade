# TecnoMath Aula

Plataforma educativa escolar integrada al proyecto MindMathArcade.

Incluye:
- selector de estudiantes predefinidos
- materias
- exámenes y quizzes con autocorrección
- talleres y tareas
- recursos educativos
- avisos
- registro de entregas en Supabase
- interfaz responsive para celular y PC

Ruta: `aula/index.html`
