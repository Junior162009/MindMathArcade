# Space Mission

Simulador educativo de viaje espacial creado con HTML, CSS y JavaScript.

## Cómo ejecutar el juego

1. Descomprime la carpeta.
2. Abre `index.html`.
3. Se abrirá automáticamente en tu navegador.
4. Selecciona un planeta y una nave.
5. Inicia la misión.

## Funciones incluidas

- Selección de planeta.
- Selección de nave.
- Combustible y oxígeno.
- Reabastecimiento de recursos.
- Barra de progreso de 0% a 100%.
- Movimiento visual de la nave.
- Desafíos aleatorios durante el viaje.
- Falla crítica con operaciones matemáticas.
- Sobrecarga con secuencias.
- Fallo del motor con código numérico.
- Lluvia de meteoritos con preguntas de capitales.
- Tiempo de lectura antes de iniciar cada desafío.
- Temporizador que comienza solo cuando el jugador pulsa "ESTOY LISTO".
- Misión completada o misión fallida.

## Archivos

- `index.html`: estructura de la aplicación.
- `style.css`: diseño visual.
- `game.js`: lógica del juego.
- `README.md`: instrucciones del proyecto.

## Tecnologías

- HTML5
- CSS3
- JavaScript
