- `games/downloader/HorrorSchool/images/2.jpg`

Coloca las capturas originales en esas rutas, respetando los nombres y las mayúsculas/minúsculas. No se incluyen imágenes de reemplazo. Las miniaturas abren una vista ampliada con botones anterior/siguiente; también funcionan las flechas del teclado y Escape.
